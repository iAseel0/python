 🎮 Tic-Tac-Toe Interactive Dashboard

A modern, graphical Tic-Tac-Toe desktop application built using Python and Tkinter. Featuring custom styling, pastel color palettes, flexible game modes, and smooth gameplay logic.


 Features
 Game Modes: Single Player (vs. Computer) & Two Players mode.
 Symbol & Turn Options: Choose between X or O and decide who starts first.
 Modern GUI Design: Clean pastel color theme with rounded dashboard components.
 Real-time Updates: Instant game status notifications, win detection, and draw tracking.


 🛠️ Built With
 Language: Python 3
